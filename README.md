## How to Deploy

### Option 1: Vercel (Recommended)

1. Install Vercel CLI: `npm i -g vercel`
2. Login: `vercel login`
3. Deploy: `vercel --prod`
4. Follow the prompts

### Option 2: GitHub Pages

1. Push to GitHub repository
2. Go to Settings → Pages
3. Set source to `main` branch
4. Save and wait for deployment

### Option 3: Netlify

1. Drag and drop the folder to https://app.netlify.com/drop
2. Wait for deployment
3. Get your live URL

## Local Development

Simply open `index.html` in your browser or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (if you have npm)
npx serve .
```

## Customization

1. **Colors**: Edit CSS variables in the `:root` selector (lines 20-31)
2. **Content**: Update HTML sections with your information
3. **Projects**: Add/remove project cards in the projects section
4. **Contact**: Update email and phone numbers in the contact section
